# 局限与后续工作

## 一、当前局限

| 方向 | 局限 |
| --- | --- |
| 硬件 | 当前主要基于 QEMU 验证，缺少稳定的目标 CPU 真机性能数据 |
| SME 微内核 | 当前面向 `cntw == 16`，即 512-bit SME vector length |
| 算子覆盖 | 已覆盖常用 AI 算子，但 attention 内部 QK^T、P*V 仍可继续 SME 化 |
| llama.cpp | 自研优化集中在 Q2_K 路径，Q3_K、Q6_K 等量化格式未覆盖 |
| 编译器 | 未直接修改 GCC/LLVM 后端自动生成 SME 矩阵代码 |
| 工程化 | 尚未形成跨平台 CI，验收依赖本地工具链和 QEMU 路径 |

## 二、后续优先级

1. 在支持 SME1 的目标 CPU 上补真实性能数据。
2. 扩展更多 ggml 量化格式，如 Q3_K、Q6_K。
3. 将 attention 的 QK^T、P*V 独立接入 SME 微内核。
4. 增加更多矩阵规模和 batch 规模测试。
5. 将成熟微内核沉淀为可自动选择的算子调度机制。
6. 继续研究编译器自动识别矩阵模式并生成 SME 指令的路径。

## 三、结题表述边界

建议表述：

> 项目完成了 SME1 AI 运算库和 llama.cpp Q2_K 推理路径接入，形成可运行、可验证的软件发布包。

不建议表述：

> 项目已经完成所有 AI 模型和所有量化格式的 SME 加速。

不建议表述：

> 项目已经在真实飞腾硬件上取得确定性能提升。

除非后续补充了真机实验数据。
